# ワザエンジン（部分実装）

`scripts/compile-attacks.mjs` が全カードのワザを `data/cards/attack-effects.json` に記録する。
印刷されたダメージ、エネルギー、ワザの原文を保存し、原文全体を理解できた場合のみ
`supported` にする。未知の文章、変動ダメージ、未対応のエネルギーは `needs_review`。
これはワザごとの解析状態であり、カード全体の `engine.status` は変更しない。

`AttackEngine` は対応したワザについて、ワザの必要エネルギーと特性の制限を確認し、
相手へのワザのダメージに弱点・抵抗力・対応済みの特性による軽減を適用する。
現在の効果はドロー、このポケモンへのダメージ、スボミーのワザによる
次の相手の番の手札からのグッズ使用禁止。禁止は `canPlayItemFromHand` で判定し、
相手の番を終えると解除する。グッズ自体の効果は未実装。

単独のきぜつでは、バトルポケモンと付いているエネルギーをトラッシュに移し、
カードDBの明示されたルール文に従ってサイドを1/2/3枚取得する。
どのサイドを取るかと次のバトルポケモンは `getKnockoutActions` の合法手から選ぶ。
サイドを取り切るか相手の場からポケモンがなくなると勝敗を決める。
相手の番に自分のポケモンがきぜつした履歴は、次の自分の番のキチキギスexの
「さかてにとる」でも参照される。自分の番の反動できぜつした場合には発動しない。

同時きぜつ、特別なサイド変更効果、カードDBでサイドの特別ルールを確認できない
ポケモンexは解釈を推測せず処理を停止する。通常対戦のセットアップ・山札切れ・
ポケモンチェックなどはまだ未対応。状態異常、ダメカンをのせる効果、
特殊エネルギー、変動ダメージ、ワザを使う直前の効果、残る特性・トレーナーズも未対応。
この試験画面は通常対戦の合法手を網羅しない。`npm test` で実カードの例を確認できる。
