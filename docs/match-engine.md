# 通常対戦盤面（対応済みカードの試験）

`index.html` は `MatchEngine` の合法手を使って実カードを操作する盤面。
シードを指定して同じ初手とサイドを再現できる。自分には
スボミー、ヘラクロス、キチキギスex、オーガポン みどりのめんex、
メガガルーラex、ラティアスexを各4枚、基本草エネルギー36枚の
サンプルデッキを配る。相手には公式デッキコード
`nnNNLn-xCvlKh-69gNPQ` の60枚を `data/decks/opponent-festival.json` の
公式カードIDと枚数どおりに配る。手札は両方見える１台共有の試験画面。

対応する基本操作：60枚デッキのシャッフル、初期手札7枚・サイド6枚、
両者の初期バトル場・ベンチ、番の最初の1枚、先攻最初の番のワザ禁止、
手札のたねポケモンをベンチに出す、基本エネルギーの手貼り1枚、
にげる1回とエネルギーのトラッシュ、対応済みの進化、特性、ワザ、
単独のきぜつ、サイド選択、ベンチ交代、サイド・場・山札切れの勝敗。
初手に対応済みの特性を持つたねポケモンがない場合は引き直す。
本デッキの未対応特性のたねポケモンは現在の試験では場に出せない。
相手の追加ドローはまだ未対応。

場に未知の特性がある場合、対応外のワザや特殊エネルギー・グッズ・
サポート・スタジアム・ポケモンのどうぐ・特殊状態などは処理しない。
お祭り会場デッキの主軸「おまつりおんど」「ドンドンだいこ」も未実装なので、
デッキの60枚は再現できても元のデッキどおりの戦術で対戦することはできない。
同時きぜつも安全のため保留する。シードを記録して状態を再現できるが、
正式な大会ルールを網羅した対戦エンジンではない。

`npm test` で初期セットアップからターン進行までの決定論的テストを行う。
